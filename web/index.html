🌐 How to Get Permanent Public URLs for Discord Portal

Discord requires public HTTPS URLs (not localhost). Choose any of these 100% free methods:

Zero Cost

GitHub Pages (Recommended)

Cloudflare Pages / Vercel

Drag-and-drop your docs folder to Cloudflare Pages or Vercel for an instant custom HTTPS domain:

https://your-bot.pages.dev/terms.html
3

Instant Cloudflare Tunnel

If you run python web_panel.py on your PC, you can instantly make it public with Cloudflare Quick Tunnels without port forwarding:

npx cloudflared tunnel --url http://localhost:5000
